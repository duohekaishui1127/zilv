# 安全与隐私设计

## 服务端授权

- 客户端提交的 userId 不被信任；身份始终来自微信上下文 OPENID。
- 好友、群组、Note 关联实体的所有权均由服务端重新检查。
- Note API 只允许 owner 访问。

## 数据最小公开

好友默认只看到计划状态等经用户授权的信息；体重、体脂、围度、饮食明细、训练详情保持私密。

群组的强监督权只覆盖计划群组绑定后的完成状态，不覆盖其他个人数据。

## 日志最小化

运行日志只记录：requestId、action、脱敏 userId、耗时、错误码。

审计日志只记录：userId、action、requestId、entityId、时间。

不写入：体重值、饮食内容、Note 正文、图片 URL 等敏感 payload。

计划提醒只发送计划名称、提醒时间和“尚未打卡”状态，不发送身体、饮食、日志或照片数据。订阅消息必须由用户在小程序内主动授权。

## 云存储

日志图片通过微信云存储保存，数据库只保存 fileId。建议在真实云环境中配置最小化存储安全规则，并避免把 fileId 作为公开分享链接使用。
