# 小程序页面原型（1.6.0）

## 自律日历（默认首页）

```text
< 2026-09 >
一 二 三 四 五 六 日
   1[心情] 2   3[完成] 4

点击日期 → 当前页底部浮层
备注小记：默认直接展示
完成任务 3项：默认折叠，可手动展开
点击遮罩空白处关闭
```


## 日志编辑器

```text
类型：体态
日期：2026-09-16
标题：________
内容：____________________
标签：减脂，肩背

图片（最多9张）
[照片] 正面
[照片] 侧面
[照片] 背面

仅自己可见
[保存记录]
```

编辑器支持本地草稿恢复；学习和训练历史记录可以直接进入带关联关系的编辑器。

## 我的

```text
我的历程              >
身体数据（定期更新）    >
趋势与复盘            >
其他                  ⌄

展开后：
身体与营养档案 / 今日页设置 / 隐私设置
自定义食物 / 意见与建议 / 关于与诊断
```

消息中心不在“我的”重复提供入口；统一由“今日”右上角灰色消息图标进入，有未读时显示红点。

## 趋势与复盘

```text

```

## 计划提醒

```text

```
