# 1.6.0 验收测试清单

## 首次使用与版本
- [ ] 新用户首次进入可自动创建用户、隐私和营养档案。
- [ ] 数据库未初始化/Schema 过旧时 API 明确拒绝执行。
- [ ] “关于与诊断”显示客户端/服务端 1.6.0、Schema 15。
- [ ] 管理员好友列表中同一用户只出现一次；运行 `admin-init` 后历史重复关系标记为 `DUPLICATE`。
- [ ] 习惯连续完成目标天数时先生成达成消息，再自动归档；考试目标在剩余 200、100、30、7、1 天时各生成一次消息。
- [ ] 长期目标页不显示提醒开关；创建、编辑和触发目标提醒时均不申请微信订阅，消息中心提醒默认生效。
- [ ] 今日页考试目标突出显示倒计时；无关联任务时不显示“近7天 0/0”，有关联任务时才显示近七天执行进度。
- [ ] 考试日当天目标自动从“今日”和进行中列表移除，不出现逾期；“我的 → 我的进步”可查看创建日期、考试日期、准备天数、关联任务、完成次数、学习时长和完成率。
- [ ] 已归档考试可选择待出分、已通过、未通过或未参加，分数和复盘备注可留空；待出分满 60 天只生成一次消息中心提醒。
- [ ] 创建数量积累目标时自动生成唯一执行任务，普通执行任务的绑定列表不出现数量积累目标，托管任务不能单独启停、删除或关联其他长期目标。
- [ ] 100 天累计 5000 词且每天执行时，初始建议量为每天 50 词；改为每周 3 次后只调整未来建议量，不改写历史打卡。
- [ ] 无上限数量目标持续累计每次打卡的实际数量，不显示百分比；主动结束后目标和托管任务一起收起并进入“我的进步”。
- [ ] 有上限数量目标达成后自动归档，托管任务同步收起；主动提前结束显示“已结束”而不是“已达成”，历史数量、次数和用时均保留。

## 计划专注计时
- [ ] 创建计划时可选择不计时、正计时或倒计时，倒计时限制为 1～1440 分钟。
- [ ] 正计时支持开始、暂停、继续和结束，并正确区分有效、总用时和暂停时间。
- [ ] 正计时累计有效时间达到 2.5 小时后只提醒休息，不停止计时、不完成任务；前台振动，后台使用一次订阅消息。
- [ ] 正计时提醒额度已消耗时，手动完成任务会申请下一次额度；额度未消耗时直接留给下一次计时，不重复弹窗。
- [ ] 倒计时暂停后不递减，达到有效时间目标后自动结束计时但不自动完成任务。
- [ ] 切换导航栏或重新进入小程序后，正在进行的计时能按服务端时间恢复。
- [ ] 同一时间不能同时启动两个计划计时器。
- [ ] 结束计时后直接完成任务，之后点击已完成任务可以补充可选备注。

## 自律日历
- [ ] 小程序启动后默认进入“日历”，底部导航保持 5 项。
- [ ] 完成最后一项今日计划后自动打卡、更新连续天数，并自动弹出整日心情与今日小记。
- [ ] 日历只使用整日打卡心情作为当天的黑白像素印记。
- [ ] 点击日期在当前页面打开详情浮层，点击遮罩空白处关闭。
- [ ] 当天备注小记及图片默认直接显示，完成任务默认折叠且可展开。
- [ ] 展开的任务显示分类、完成时间、有效/总/暂停时间和可选备注。

## 用户反馈与版本公告
- [ ] 普通用户可以提交文字、最多 3 张截图和可选联系方式。
- [ ] 重试同一个 clientMutationId 不会重复创建反馈。
- [ ] 普通用户只能提交并读取自己的反馈、处理状态和开发者回复。
- [ ] 配置的反馈管理员只显示反馈管理入口，收到消息中心提醒后只能读取其他用户的反馈。
- [ ] 非管理员无法调用反馈管理接口。
- [ ] 管理员修改状态后，提交用户会收到消息中心通知。
- [ ] 管理员可选择快捷回复或输入自定义回复；发送后用户在消息中心和自己的反馈记录中看到回复。
- [ ] 管理员不能回复自己的历史反馈，重复回复会更新最近回复并生成新的消息中心通知。
- [ ] 同一个版本公告 id 对同一用户只投递一次。

## 身体与营养

- [ ] 保存身体记录后可以继续创建关联体态日志。

## 好友与群组
- [ ] 发送好友申请后，对方收到消息中心通知，圈子标签及好友入口显示红点。
- [ ] 从好友码或群成员日历发送申请时，可填写最多 60 字的选填备注；接收方在申请列表和消息中心均可看到。
- [ ] 群成员日历正确显示“＋好友”、申请中、待处理或已是好友状态，不能给自己发送申请。
- [ ] 对方可以接受或拒绝；申请方可在处理前撤回，处理结果会通知申请方。
- [ ] 同一申请人在被拒绝 24 小时内、主动撤回 5 分钟内不能反复发送申请。
- [ ] 接受好友后提示当前使用统一好友隐私设置，并可进入“我的”调整。
- [ ] 点击好友进入资料页显示当月打卡日历；可见日期显示计划名称、逐项完成状态和完成数/总数，所有可见计划完成后才显示绿色对号，绝不返回计划内容、任务备注、整日心情、小记或计时详情。
- [ ] 好友右上角可设置仅本人可见的备注、特别关心、微信提醒和“我向 TA 公开”的单好友权限例外。
- [ ] 好友可单独置顶或取消置顶；置顶只影响本人好友列表，新置顶好友会立即移动到首位，取消后回到未置顶区域。
- [ ] 单好友权限关闭时跟随全局设置，特别关心不能绕过对方隐私。
- [ ] 删除好友会同时关闭双方特别关心并删除双方单好友设置。
- [ ] 好友仅看到隐私设置允许的状态。
- [ ] 群组仅强制公开绑定计划的执行情况。
- [ ] 群组列表显示人数和群组 ID，复制按钮不误触进入详情。
- [ ] 每名成员可为群聊设置仅本人可见的备注并置顶/取消置顶；群详情显示本人备注，同时保留原群名称提示。
- [ ] 新置顶的群聊会立即移动到群组列表首位；群主可二次确认后解散群聊，所有成员均不再看到该群，绑定计划自动解除，旧邀请不能再次加入。
- [ ] 群主可开启入群审批、配置 1～365 天连续未打卡自动移出，并决定自动移出后是否禁止再次加入；普通成员不能修改。
- [ ] 开启审批后，申请人不会直接成为成员，群主可在群详情同意或拒绝；被禁止重新加入的成员无法通过群 ID 或邀请绕过限制。
- [ ] 群主可单独移出普通成员，并可选择允许重新申请或禁止再次加入；被移出成员的群绑定即时失效。
- [ ] 邀请面板可多选好友或输入个人 ID；对方消息中心收到邀请，确认后加入，同日重复邀请不会重复写消息。
- [ ] 群组详情不再重复显示邀请码卡片、成员标题说明或微信提醒开关。
- [ ] 未完成成员置顶并按完成比例升序；无绑定计划居中；全部完成成员灰度沉底，群主身份仍可辨认。
- [ ] 点击群成员进入当月打卡日历，入群前和未来日期不显示记录；入群日至今天可查看计划名称、逐项状态和完成数/总数，所有群绑定计划完成后才显示绿色对号，不返回计划内容、心情、备注、小记或计时详情。
- [ ] 绑定计划的发布者若是相关群群主，该群自动批准且不显示自审申请；仅绑定到本人管理群组时变更直接生效，同时向相关群写入动态并通知其他成员。
- [ ] 同一计划还绑定到他人管理的群组时，只等待这些群主审批；全部同意后变更生效并向所有相关群广播，任一群主拒绝则不变更。
- [ ] 同群关系不能读取体重、饮食、日志或体态照片。
- [ ] 用户可通过微信头像选择器主动授权头像，头像上传后在个人页、好友详情与群成员列表显示；未授权时保持占位头像。
- [ ] 每完成一项绑定计划，无论当天是否全部完成、是否订阅微信消息，群详情和其他成员消息中心都会立即出现该项动态。
- [ ] 打卡动态默认折叠，展开后显示具体记录、时间戳和点赞按钮。
- [ ] 群成员可点赞或取消点赞有效打卡动态，撤回的动态不可点赞。
- [ ] 好友设为特别关心后，即使不在同一群，也能在圈子首页看到其获准公开的打卡。
- [ ] 撤回已完成任务后，当日自动打卡和日历印记同步取消，群内显示撤回状态；重新完成可恢复。
- [ ] 群组只保留单项任务动态和消息中心广播；特别关心的微信提醒仍由好友设置单独授权。

## 整日打卡提醒与消息中心
- [ ] “我的 → 打卡提醒”位于“我的历程”上方，可设置提醒时间或关闭提醒。
- [ ] 新建/编辑计划页和群组详情均不再显示打卡提醒设置。
- [ ] 到达提醒时间但今日全部任务已经完成并自动打卡时不生成消息。
- [ ] 指定星期、结束日期和每周次数完成状态均能阻止无效提醒。
- [ ] 同一用户同一天重复执行定时函数只生成一条整日打卡消息。
- [ ] 今日页右上角是消息中心唯一常用入口：有未读显示红点，全部已读后恢复灰色图标。
- [ ] 消息列表中未读项高亮、已读项变灰，并支持单条和全部已读。
- [ ] 每名用户最多保留最近 20 条通知，第 21 条写入后最旧通知被清理，旧版本公告和同日提醒不会因此重复出现。
- [ ] 用户主动同意订阅后可以收到一次微信服务通知。
- [ ] 现有一次性提醒尚未发送时，完成最后一项任务不会重复申请；实际发送消耗后，下一次完成最后一项任务才申请并自动登记新机会。
- [ ] 完成任务只提示“今日打卡完成”，不额外展示整日打卡提醒的续订过程。
- [ ] 同一用户即使有多个未完成计划，也只尝试发送一条整日微信服务通知。
- [ ] 一次性微信提醒发送成功或检测到无订阅权限后，全局打卡提醒显示为等待补充下一次机会。
- [ ] 配置长期订阅模板时，授权一次后微信提醒开关在发送成功后保持，后续应执行日仍可提醒；一次性模板仍在成功发送后关闭。
- [ ] 拒绝微信订阅不影响站内消息中心提醒。
