# 自律品牌素材

- 小程序名称：`自律`
- 微信公众平台上传图标：`app-icon.png`（144 × 144 PNG）
- 高清设计源图：`app-icon-source.png`（1254 × 1254 PNG）

`project.config.json` 中的 `projectname` 只控制微信开发者工具里的项目名称，`miniprogram/app.json` 中的 `navigationBarTitleText` 只控制小程序页面标题。

体验版入口、最近使用和分享卡片显示的小程序名称与头像来自微信公众平台的小程序账号资料。上传体验版前，请使用当前 AppID 的管理员账号登录微信公众平台，在账号基本信息中将名称设为“自律”，并上传 `app-icon.png`。
